## Pattern ricorrenti (ispirazione per `/chi-siamo`)

| Pattern | Esempi | Applicabilità Gramazio |
|---------|--------|------------------------|
| Arco storico (date o generazioni) | Bigucci, Cacioli, Biorussi, Spinelli | Solo dopo dati confermati dall'azienda |
| Territorio come sezione | Bigucci (pagina), Conforti, Cannarozzi | Carpino, Parco Gargano, Città dell'Olio — già in linea con fonti pubbliche |
| Persone e ruoli | Ottaviani, Biorussi, Vaira | Richiede nomi/foto approvati |
| Filosofia produttiva (bio, freddo, tempi) | Ottaviani, Conforti, Tripaldi | Solo claim documentati (es. bio, cultivar autoctone — Cibovagare) |
| Prodotti oltre l'olio (fava, trasformati) | Cannarozzi, Cibovagare | Olio + fava + linee citate in scheda evento |
| Certificazioni / Presidi | Cannarozzi (Slow Food), Ottaviani (bio frantoio) | Inserire solo certificazioni verificabili |
| Hub multi-pagina | Bigucci (chi-siamo + territorio + produzione) | Opzionale se il contenuto cresce |
| CTA visita / contatto / catalogo | Ottaviani, quasi tutti | Allineato al modello catalogo + ordine del sito |
